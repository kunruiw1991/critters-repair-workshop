# 中文配音接入

游戏默认使用设备上的普通话语音。这不是洛天依的声音，也没有打包洛天依音频。

`script.json` 是实际会朗读的 24 句中文台词。获得可用的官方声库并生成配音后，将导出的音频放进项目中的 `voices/` 文件夹，再在 `manifest.js` 中按完整台词配置路径，例如：

```js
export const VOICE_CLIPS = {
  '我已经修好啦！现在送我一颗唤醒爱心吧。': 'voices/heart-ready.mp3'
};
```

配置过的句子直接播放录音；未配置的句子使用普通话设备语音。全静音、暂停、继续和返回首页也会控制录音播放。
