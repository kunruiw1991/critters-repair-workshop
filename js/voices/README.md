# 中文配音接入

游戏已内置 24 段中文 MP3 配音，使用微软晓伊（zh-CN-XiaoyiNeural）合成声音，偏活泼、明亮。播放不依赖设备是否安装中文声库。这不是洛天依的声音。

`voices/source.json` 记录了声音和生成参数。音频加载失败时才使用设备普通话语音。

`script.json` 是实际会朗读的 24 句中文台词。若以后更换声音，将导出的音频放进项目中的 `voices/` 文件夹，再在 `manifest.js` 中按完整台词配置路径，例如：

```js
export const VOICE_CLIPS = {
  '我已经修好啦！现在送我一颗唤醒爱心吧。': 'voices/heart-ready.mp3'
};
```

配置过的句子直接播放录音；未配置的句子使用普通话设备语音。全静音、暂停、继续和返回首页也会控制录音播放。
